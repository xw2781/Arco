Dataset Viewer

Inspect a triangle or vector

Read the data, check its identity and period lengths, and record the observations that support your review.

Demo project: ABC_Group_Quarterly_Review_202608

Open Gross Loss--Paid

  1. Open the demo Project Page and select ABC Auto → PPA → NJ → Exclusive → BI Full Tort.
  2. Find Gross Loss--Paid in the dataset table and double-click its row.
  3. On Data, confirm the dataset name, cumulative view, and 12-month origin and development lengths.
  4. Read the latest available cell in each origin row. Blanks beyond the triangle boundary represent unavailable future development.

Check the Dataset's Identity

  1. Open Details and inspect Name and Dataset Type.
  2. Check Precedents to see what feeds the dataset and Dependents to see which outputs use it. Click a listed dataset or method to inspect it.
  3. When a formula is shown, read it as the definition of the calculated dataset. Its definition is maintained in Project Explorer's Dataset Types.

To inspect a method's output as data, return to the Project Page, right-click its vector row, and choose Show as vector.

Change the View and Copy Values

  1. On Data, use the available view controls to inspect cumulative/incremental values, development/calendar layout, or a transposed view.
  2. Choose Number Format and Decimal Places to make the amounts easy to read.
  3. Select a cell or drag a rectangular range, then press Ctrl + C to copy values. Use row or column headers to select larger ranges.
  4. Open Chart to compare series. Use its legend checkboxes to show the lines you need; right-click a legend item to isolate it.
Some controls are intentionally read-only

Manual input datasets can have editable values. Generated, calculated, and method output values come from their sources or owning method. Change those sources instead of trying to type over the output grid.

Record and Save Your Review

  1. Open Notes and record the reason for your review, for example: “Jordan Lee: checked the latest Gross Loss--Paid diagonal.”
  2. If editable cells use Excel references, open Links to inspect or refresh their sources before saving.
  3. Choose Save or press Ctrl + S. Wait for the save and any dependent-update report.
  4. Open Audit Log to inspect saved changes, then return to the Project Page.

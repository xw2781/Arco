Project Explorer and Settings

Check how the project is defined

Use Project Explorer to inspect the source data, segment structure, dataset types, and dates that the rest of the project uses.

Demo project: ABC_Group_Quarterly_Review_202608

Select the Demo Project

  1. From Home, choose Project Explorer.
  2. Expand Test/Demos and single-click ABC_Group_Quarterly_Review_202608 to inspect its configuration.
  3. Use the ribbon to move between Source Data, Field Mapping, Reserving Class Types, Dataset Types, Data Processing, Audit Log, and Project Settings.
  4. Double-click the project in the tree when you want to open its Project Page and work with dataset instances.

Check the Source and Periods

  1. Open Source Data and check the source identity and the origin/development date boundaries.
  2. For this guide, check the 2017–2026 origin span and August 2026 development end date. The dataset walkthrough uses 12-month origin and development lengths.
  3. Open Field Mapping to see which source fields supply dataset values and segment levels.
  4. Open Reserving Class Types to inspect the hierarchy. The walkthrough's selected path is ABC Auto → PPA → NJ → Exclusive → BI Full Tort.

Use the source panel's Table details and Import settings controls when you need more information about the source. A source refresh affects project data; inspect the configured source before starting one.

Understand Dataset Types

In Dataset Types, find Gross Loss--Paid and check its data format and category. Find F 13 - Paid DFM w/ Selected LDFs to identify the output type used in the DFM walkthrough.

A dataset type is a project definition. A dataset instance is the named triangle or vector you open for one segment on the Project Page. A method's Name and Output Type can therefore differ.

Changes can affect existing work

Dataset Types edits save automatically. When an edit affects existing datasets, review the Confirm Dataset Type Change list before choosing Apply. Cancel returns to the saved definitions. Wait for the displayed save or processing result.

Review a Configuration Change

  1. Open Audit Log to inspect recorded changes.
  2. Return to the Project Page and select the demo segment.
  3. Use Refresh Table, reopen the affected dataset, and check its periods and values.

Continue with Dataset Viewer to inspect the actual data.

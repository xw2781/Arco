Excel Add-In

Bring the demo's values into Excel

Use the Arco add-in to insert a dataset formula, refresh its results, and save a workbook that carries the reviewed values.

Demo project: ABC_Group_Quarterly_Review_202608

Identify the Dataset First

  1. In Arco, open ABC_Group_Quarterly_Review_202608 and select ABC Auto → PPA → NJ → Exclusive → BI Full Tort.
  2. Open Gross Loss--Paid and check its annual cumulative view before requesting the same data in Excel.
  3. In Excel, confirm the Arco ribbon is available. Use the installed add-in supplied for your environment.
  4. Choose Connect and Login and check the workbook's project connection.

Insert a Triangle Formula

  1. Select an empty worksheet cell with room for the triangle to spill into the rows and columns beside it.
  2. Choose Arco → Insert Function, then select ArcoTri.
  3. Choose the demo project, segment path, and Gross Loss--Paid. Use TRUE for Cumulative, FALSE for Transposed and Calendar, and 12 for both period lengths. You can leave an optional field blank when its displayed default matches.
  4. Inspect the formula preview and insert it. Check that values appear in the intended cells.

You can also put the project in B2, the path in B3, and the dataset name in B4, then enter:

B2: ABC_Group_Quarterly_Review_202608
B3: ABC Auto\PPA\NJ\Exclusive\BI Full Tort
B4: Gross Loss--Paid

=ArcoTri($B$3,$B$4,TRUE,FALSE,FALSE,$B$2,12,12)

Use ArcoVec for a vector such as F 13 - Paid DFM w/ Selected LDFs. Load Reserving Classes and Select Datasets help fill paths and names; Refresh lists updates the Insert Function panel's available choices.

Refresh and Share the Workbook

  1. Choose Refresh Worksheet for the active sheet or Refresh Workbook for the workbook's Arco requests.
  2. Wait for refresh to finish and inspect any reported failure.
  3. Compare a few origin values with the same dataset and period settings in Arco.
  4. Save the workbook so its current Arco results travel with it.
Recalculation and refresh are different

Opening a workbook and ordinary recalculation use its saved Arco results. Entering a new request loads missing results; an explicit Refresh updates results already saved in the workbook.

Repair an Older Workbook

Use Reset Add-in References when a workbook points to an old add-in location or older supported function names. Check the target add-in and choose Update workbook, then read the repair result.

Reference repair does not fetch new project data or save the workbook. Refresh if needed, inspect the values, and save afterwards.

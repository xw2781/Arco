Project Page

Find your data and open a method

Use the segment tree to choose the data you are working on, then use the dataset table to inspect inputs and open or create methods.

Project: ABC_Group_Quarterly_Review_202608 Input: Gross Loss--Paid Finished sample: F 13 - Paid DFM w/ Selected LDFs

Open the Project and Segment

  1. In the app's Project Explorer, expand Test/Demos.
  2. Double-click ABC_Group_Quarterly_Review_202608 to open its Project Page page.
  3. In the segment tree, expand ABC Auto → PPA → NJ → Exclusive, then select Comprehensive.
  4. Check the dataset table for the selected segment. Each row represents a dataset instance; its data format and method type help you choose the correct action.

Find Gross Loss--Paid

  1. Click the funnel control in the Name column header.
  2. Choose Gross Loss--Paid to show the matching dataset.
  3. To return to the full table, reopen the Name filter and choose All.

Inspect the Input Triangle

  1. Double-click the Gross Loss--Paid row to open the dataset.
  2. On its Data tab, check that you are viewing cumulative values with Origin Length and Development Length both set to 12.
  3. Review the origin years 2017–2026. At the August 2026 valuation, the latest ages run from 8 months for the newest origin to 116 months for the oldest.
  4. Close or minimize the dataset window to return to Project Page.

Create a DFM from the Triangle

  1. In Project Page, select the Gross Loss--Paid triangle row whose Method Type is None.
  2. Right-click the row, point to Add, then choose DFM.
  3. In the new method, use My Paid DFM as the Name and F 13 - Paid DFM w/ Selected LDFs as the Output Type. Continue with the DFM Details walkthrough.
Name and Output Type have different roles

My Paid DFM is your practice method's Name. F 13 - Paid DFM w/ Selected LDFs is its Output Type. The finished example also uses F 13 - Paid DFM w/ Selected LDFs as its Name, so check which method you have opened before making changes.

Open the Saved Method or Its Vector

  1. Clear the Name filter with All, or filter for F 13 - Paid DFM w/ Selected LDFs.
  2. Find the F 13 - Paid DFM w/ Selected LDFs row with data format Vector and Method Type DFM.
  3. Double-click this row to reopen the DFM method and review its selections.
  4. To inspect its output as a dataset instead, right-click the same row and choose Show as vector.

Check Status and Refresh the Table

A method output marked Review Needed needs your attention. Open its method, inspect the inputs and selections, and save the reviewed method. Refreshing the table alone does not acknowledge the review.

The demo also includes F 23 - Incurred DFM w/ Selected LDFs and F 91 - Current Qtr Indicated. Use the Result Selection walkthrough to compare the paid and reported DFM outputs.

If data or methods changed outside the current page, use Refresh Table to reload the inventory. If a row still seems missing, check the selected segment and clear any active column filters.

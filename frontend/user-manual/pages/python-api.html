Python API

Open project data from a script

Use Arcode's bundled Python API to interact with the running Arco app and inspect the resulting dataset window.

Demo project: ABC_Group_Quarterly_Review_202608

Prepare the App and Editor

  1. In Arco, open ABC_Group_Quarterly_Review_202608.
  2. On its Project Page, select ABC Auto → PPA → NJ → Exclusive → BI Full Tort and keep that page active.
  3. Open Arcode and choose Python File. Arcode includes the API and a compatible Python runtime.

Open the Demo Dataset

from arcrho_api import ArcRhoUI

ui = ArcRhoUI()
ui.wait_for_app(timeout_sec=10)

window = ui.project_instance.open_dataset("Gross Loss--Paid")
window.maximize()
print(window.properties.as_dict())
  1. Paste the example into the Python editor and choose Run, or press Ctrl + Enter.
  2. Return to Arco and confirm the opened dataset is Gross Loss--Paid in the selected demo segment.
  3. Inspect the printed window properties in Arcode's Output panel.
  4. Run window.restore() to return the dataset window to its previous size.

This example opens a view and prints its properties. It does not change dataset values or save a method.

Refresh the Project Table After Scripted Work

When a separate script has saved new project data, use the normal Project Page refresh or call:

ui.project_instance.reload_dataset_table()

Then reopen the affected dataset or method and check its latest values and review status. A script's successful execution is separate from your review of the result.

Save your script through File → Save. Running it does not automatically save the editor file.

Use an External Python Environment

External IDEs need the first-party arcrho_api wheel distributed with your Arco release. Install the supplied wheel into the environment that will run your script:

python -m pip install "path-to-the-supplied-wheel.whl"

Keep Arco running for the UI example and use the same Windows user session. If more than one Arco window is running, select the intended app connection before automating it.

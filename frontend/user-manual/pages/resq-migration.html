ResQ Import and Review

Review a ResQ transfer before applying it

Choose the right macro for a read-only comparison, an import, or synchronization, and verify the project and segment before starting.

Demo project: ABC_Group_Quarterly_Review_202608

Start from the Intended Segment

  1. Open the Project Page for the project you intend to compare or transfer.
  2. Select its segment. The training guide uses ABC_Group_Quarterly_Review_202608 and ABC Auto → PPA → NJ → Exclusive → BI Full Tort.
  3. Open Macro and read the selected ResQ macro's description.
  4. Confirm that the corresponding ResQ project and segment are available through your organization's configured ResQ service before starting a transfer.

Compare Before Writing

  1. Select Review Reserving Class against ResQ and choose Run.
  2. Wait for the comparison to finish and open its Excel workbook.
  3. Use the workbook's Summary links to inspect differences between Arco and ResQ values, Result Selections, and DFM notes.
  4. Resolve unexpected differences before choosing a write action.

This review macro reads both sides and produces a comparison workbook. It does not write changes back to Arco or ResQ.

Import Selected ResQ Items

  1. Select Import ResQ Reserving Class and choose Run.
  2. In the transfer review, tick only the datasets and methods you intend to import.
  3. Inspect any warning that an Arco copy is newer. Follow the item links to review it before accepting an overwrite.
  4. Confirm the overwrite only when the selected ResQ copies should replace those Arco items, then wait for the final result.
An import changes Arco data

The import takes a dated backup of the existing class before replacing selected items. The confirmation still matters: importing is a write operation, while the comparison macro above is read-only.

Check the Imported Result

  1. Return to the Project Page and choose Refresh Table.
  2. Open imported triangles and vectors, and compare their origin labels, period lengths, and values.
  3. Open imported DFM or Result Selection methods to inspect selections and Notes.
  4. Read the import result for warnings or failed items before relying on the output.

Sync Reserving Class with ResQ is a separate workflow that previews the comparison and proposed direction before applying changes. Read that direction carefully; use the read-only review macro when you only need a comparison.

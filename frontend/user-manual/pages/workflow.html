Workflow

Organize a repeatable review

Keep dataset views and DFM steps in one named workflow, with a shared project and segment.

Demo project: ABC_Group_Quarterly_Review_202608

Create a Workflow

  1. On Home, choose New Workflow.
  2. Click Workflow Designer or its rename control and name the workflow Jordan Lee — Paid Review.
  3. Click the + tile in the left panel to add a step, then choose Global Control.
  4. Set the default project to ABC_Group_Quarterly_Review_202608 and the default path to ABC Auto → PPA → NJ → Exclusive → BI Full Tort.

Add a Dataset and DFM Step

  1. Add another step and choose Open Dataset. Select Gross Loss--Paid and use the workflow defaults for the project and segment.
  2. Check the dataset's 12-month origin and development lengths and its cumulative view.
  3. Add a DFM step. Configure its details using the DFM walkthrough.
  4. Right-click a step to Rename it, or Duplicate a step when you need a similar review view.

Use New Folder from the step menu to group related work, then drag steps into the desired order. Select each step to inspect its own settings and output.

Available step types

Open Dataset, DFM, and Global Control have working editors. The workflow's Result Selection card is a placeholder; open a Result Selection method from the Project Page instead.

Save and Reopen the Workflow

  1. Choose File → Save or press Ctrl + S to save the workflow.
  2. Use File → Save As when you need a separate workflow file, and give it a recognizable name.
  3. To reopen a saved workflow, use Import from Path... on an empty workflow, or File → Import Workflow from....
  4. After loading, inspect Global Control and each step before continuing the review.

Saving is explicit. Before closing, save the workflow and check any dataset or method save messages, including errors from work embedded in the steps.

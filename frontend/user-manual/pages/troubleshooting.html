Troubleshooting

Find the cause before repeating an action

Start with the selected project, segment, and visible message. Then check the connection, inputs, or save result that the task depends on.

Demo project: ABC_Group_Quarterly_Review_202608

A Dataset Is Missing

  1. Confirm the project is ABC_Group_Quarterly_Review_202608 and the Project Page path is ABC Auto → PPA → NJ → Exclusive → BI Full Tort.
  2. Clear active table filters. For the Name filter, choose All.
  3. Choose Refresh Table after data was created or changed elsewhere.
  4. Check the expected data format and Method Type. A method output is usually a vector row that opens its method when double-clicked.

Data Will Not Load

  1. Open Server Connections from Home and confirm which server is in use.
  2. Choose Refresh. If asked to sign in again, use Sign in again and read its result.
  3. Check the Components panel and preserve any connection message.
  4. After access is restored, reopen the affected dataset or use the page's refresh action.

See Server Connection for setup and switching. If the server remains unavailable, share the visible error and active server name with the administrator.

The Values or Periods Look Wrong

  • Compare the same dataset name, segment, Origin Length, Development Length, and cumulative/calendar mode.
  • For the annual demo, check 12/12 lengths and the August 2026 valuation. A latest age of 8 months for the newest origin is expected.
  • If the grid is read-only, inspect the generating source, formula, or owning method. Derived values are not edited directly in Dataset Viewer.
  • For an Excel comparison, use an explicit add-in Refresh; ordinary recalculation may still show the workbook's saved snapshot.

A Save or Review Needs Attention

Wait for the save result and read the complete message. A source can save successfully while a dependent recalculation reports a failure; inspect the named dependent before treating the whole chain as complete.

For a method marked Review Needed, reopen it, inspect the inputs and selections, and save the reviewed method. Refreshing the table alone does not acknowledge that review.

If another operation is still processing the same project or segment, wait for its outcome before retrying. Keep the method open while resolving a save problem so you can inspect its unsaved work.

Send a Useful Problem Report

Record the page or method name, project and segment, the exact action, the full message, and whether the issue happens again after reopening the view. Include a screenshot with the relevant controls and result visible.

For presentation issues, save open work before using Settings → Clear Cache & Reload. A reload does not correct a failed server calculation or an incorrect source definition.

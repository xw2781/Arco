Server Connection

Check which server Arco is using

Confirm the active server, renew sign-in when needed, and switch only after saving your open work.

Demo project: ABC_Group_Quarterly_Review_202608

Inspect the Current Connection

  1. On Home, choose Server Connections to open the Server tab.
  2. Find the server marked as in use and check its name and address.
  3. Choose Refresh to update the displayed server information.
  4. If Arco asks you to sign in again, choose Sign in again on the active server row and read the result.

Enter Connection Details

  1. Open Settings → Server Connection.
  2. Enter the administrator-provided Root Path, or choose it with Browse....
  3. Enter the corresponding Server Address, then choose Save.
  4. Read any sign-in or connection message before continuing. Use Open Server Tab to inspect the configured server.

Use the address supplied for your environment. The project name ABC_Group_Quarterly_Review_202608 is not a server address or root folder.

Switch to Another Configured Server

  1. Save any open dataset, method, workflow, or editor changes.
  2. On the Server tab, choose the other server's Switch action.
  3. Check the destination in the confirmation, then choose Switch and Restart.
  4. After the restart, confirm the active server and reopen the intended project.

Add Server lets you register another administrator-provided Folder, Name, and Address. A window marked Set at launch has its server fixed for that session, so switching and adding are unavailable.

Use Status to Diagnose a Problem

The Components panel shows whether the active server's services are reporting. If the server cannot be reached, preserve the displayed error and ask the server administrator to check the connection and service state.

Use Help → User Guide to open the guide from the active server. If Arco asks for a server address first, return to Settings → Server Connection.

Once connected, continue with the Project Page walkthrough.

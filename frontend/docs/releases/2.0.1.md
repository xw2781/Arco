# Release 2.0.1

Released on 2026-10-22.

## User-Facing Changes

### Features
- **project settings**: Import a project's source from several SQL Server tables and CSV files joined into one table.
  - The Import Settings window lists the source as tables, with Add Table under the last one; each table has a nickname, and with two or more a Combine step shows how their keys line up and previews the result.
  - Every table is joined so that no row of any table is lost; there is no base table or join order to choose.
  - Import Data reads and joins the tables on this PC, imports the result, and refreshes the project as a single-table import does.
  - The Source Data tab names a combined source with its tables and keys, and the window reopens on its saved tables and keys.
- **result selection**: Set Result Selection weights directly on the Chart tab, and undo or redo any Result Selection change.
  - Click a point to include or exclude that method for that origin; included points are filled and sized by their share.
  - Drag a box over points to give them one weight, use only them, or exclude them.
  - The Weight strip under the chart shows each origin's split; drag a divider to shift weight between two methods.
  - Drag the Selected Ultimate point to enter a custom ultimate, or release it on a method's point to use only that method; double-click reverts.
  - Right-click a point to use only that method for one origin or from that origin on.
  - The Origin panel beside the chart lists every method's value, weight, and share for one origin, with weights you can type.
  - Weight boxes step by 1.0 with their arrows or the mouse wheel, and Edit Weights mode shows a pencil pointer over the chart.
  - Drag the side panel's left edge to make it wider or narrower; double-click the edge to reset it.
  - Zoom mode keeps the box zoom; Full View or a double-click restores the whole chart.
  - Undo and Redo buttons, Ctrl+Z, and Ctrl+Y step through every change on every tab until the window closes.

### Improvements
- **project settings**: The Import Settings window now ends on a Confirm Import page that summarises the source and scope, and Save Settings keeps them without importing.
- **shell**: The "+" button at the end of the main tab bar is removed.
- **dataset**: The Dataset Chart tab now shows every series in grey and lets you focus any of them in colour, picked from a triangle map beside the chart.
  - Plot origin curves or one age across origins, as values, incremental values, or age-to-age factors.
  - The triangle map fits any triangle size; hover it for a close-up, click an origin, age, or cell, or drag a box to zoom.
  - One readout lists the focused series and the range of the rest at the pointer.
  - Drag a box on the chart to zoom into both ages and values, or drag the strip under it; double-click to zoom back out.
  - The value axis fits the focused lines so they fill the chart.
  - Right-click an origin or age in the triangle map, or a series in the list, to show it alone.
  - Click the corner box of the triangle map to focus every series or none, or right-click it for the latest three years; shift-click focuses a range.
- **details**: Every Details tab - datasets and all method pages - now shows precedents and dependents as one small dependency map.
  - Inputs sit on the left and dependents on the right, coloured by kind like the Dependency Graph.
  - Hover a box to see its full name and formula; click it to open that dataset or method.
  - The button in the map's corner opens the full Dependency Graph with this dataset or method selected.
- **details**: Method pages now choose their input datasets directly on the Details Data Flow map instead of in separate boxes above it.
  - Each input box is labelled with its role, such as Latest or Prior Vector; use ... to change it or x to remove it.
  - An input still to choose shows as a dashed Choose box, and inputs that take several datasets end in a dashed Add box.
  - The map's row on every Details tab is now labelled Data Flow, and its boxes and arrows share the width by name length, up to sensible maximums, so long names show in full whenever there is room; the map shows no tooltips.
  - Applies to DFM, Bornhuetter Ferguson, Cape Cod, Result Selection, Berquist-Sherman and Bootstrap.

### Fixes
- **update**: Updates no longer fail on slow or shared office connections.
  - The update check reads one small file instead of the GitHub release list, so many users behind one office connection no longer use up GitHub's hourly limit, and a slow connection has 15 seconds instead of 3.
  - A dropped installer download is retried and picks up where it stopped, and a download that stops sending data gives up after 30 seconds instead of leaving the update window open.
  - Every update step is written to update.log in the app's logs folder, so a failed update can be diagnosed.

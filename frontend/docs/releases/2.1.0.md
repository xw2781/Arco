# Release 2.1.0

Released on 2026-11-09.

## User-Facing Changes

### Features
- **stochastic consolidation**: A Stochastic Consolidation can now include a bootstrap from another project, so Homeowners can combine the regular and Oil projects in one method.
  - Add Segment offers From another project, which lists that project's bootstraps.
  - Segments with fewer accident years line up at the latest year and count as zero in the earlier ones, so a ten-year segment can join a full-history one.
  - The results and total keep every year; the output vector carries only the consolidation's own project's years.
- **project settings**: A Project Dates panel changes the origin and development dates together and moves the whole project to them in one run.
  - Click the dates band on the Project Settings page to open the panel; the dates can no longer be typed over on the page itself.
  - A confirmation shows the dates before and after and what the change touches, including the origins that drop out.
  - Methods keep their exclusions, weights and selections on their own origins, new origins start empty, and hand-entered datasets follow the same rule; Excel-linked cells stay where they are.
  - A progress window and the dates band follow the change; the result lists what to review, grouped by reason, and a change that left problems can be run again.

### Improvements
- **project settings**: Field mapping is now a step of the Import Settings window, so renamed or new source columns are mapped before the import runs.
  - Mapped columns the source no longer has are listed on the step and unmapped when you save.
  - Save Settings keeps a mapping change without importing; it takes effect at the next import.
  - The Field Mapping tab has been removed.
- **formula bar**: Insert Formula is redesigned: pick a function, fill a short form with dropdowns, and see the result preview update as you go.
  - Project, reserving class, and dataset are dropdowns, and the dataset list shows only triangles or only vectors to match the function.
  - Options are checkboxes and period lengths a fixed list; quoting and default arguments are handled for you.
  - The formula text stays editable and keeps the form in step, and fx on a linked cell opens with its call filled in.
- **project settings**: A dates change no longer reports Berquist-Sherman methods that wait for values on a hand-entered triangle's new diagonal as failures.
  - The hand-entered or imported triangle is listed for review with the note that it needs values for the new diagonal; the methods that read it, and what depends on them, are not listed as problems and do not ask for the change to be run again.
- **project settings**: Project Dates accept an Origin End later than the Development End, so a mid-year valuation can keep the rest of the year's origins.

### Fixes
- **dataset**: Keep blank hand-entered triangle cells editable and linkable when the project's development end date advances.
- **build**: Include app-server services needed by macros in the packaged app.

### Breaking Changes
- **server**: The server folder is now E:\Arco Server and the Excel add-in is Arco.xlam; update to keep working.
  - Arco Workspace moves your saved server folder from E:\ArcRho Server to E:\Arco Server the first time it starts.
  - Setup registers the Excel add-in from its new place, E:\Arco Server\Excel Add-ins\Arco.xlam, and turns off the old ArcRho.xlam entry so Excel no longer reports it missing.
  - Workbooks that still name ArcRho.xlam are pointed at the new add-in with Reset Add-in References.

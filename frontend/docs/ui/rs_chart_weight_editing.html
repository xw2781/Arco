Gestures In Edit Weights

  • Click a point: include or exclude it (weight 1 ↔ 0). Same as double-clicking the source cell in Method.
  • Filled vs hollow: filled points count toward the Selected Ultimate; hollow points are excluded. Point size follows effective weight.
  • Drag a box: select points, then Set Weight, Use Only These, or Exclude. Ctrl-drag adds to the selection.
  • Weight Strip: one 100% bar per origin. Drag a divider to shift weight between two methods; it snaps at 0, 25, 50, 75 and 100%.
  • Black point: drag it up or down to enter a custom ultimate (red). Release on a method's point to use only that method instead. Double-click reverts.
  • Right-click a point: use only this method, use it from this origin on, or exclude it.
  • Origin inspector: click an origin label or strip column to type exact weights. ← → step origins.
  • Zoom mode: today's box zoom; points cannot be edited. Double-click restores the full view in either mode.

What It Changes

  • Same data as Method: writes the existing weights and custom ultimates. No new saved fields.
  • Normal save: each edit marks the method unsaved; Save works as today.
  • Hidden columns: keep their weights. The strip shows them faded so nothing counts unseen.
  • Grid sync: switching to Method shows the same weights and selected-cell highlights.

Open Decisions

  • Default mode: Edit Weights (shown) or Zoom, which keeps today's behaviour.
  • Undo: RS has no undo today. Chart-only undo, page-wide undo, or none?
  • Strip snaps: quarter steps, or free drag with Shift to snap?
  • Override drag: keep it, or leave custom ultimates to Method only?

Project Settings: Compare Mode

Concept demo. Tick two or more projects in the tree to compare them side by side. Edits stage until you save, then go to each project in one pass. All data below is sample data.

Selecting Projects

  • Tree rows get a tick box. One tick keeps today's page; two or more switch the detail area to compare mode.
  • The first ticked project is the base. Click the star on any column to change it.
  • Locked projects show as read-only columns.

Reading Differences

  • Each tab shows how many rows differ from the base, so you can see where to look first.
  • Rows are the union of every project's entries. A row a project lacks shows as Not Defined.
  • Pick one field to compare, or All Fields for the full row. Differences Only hides matching rows.

Editing Many Projects

  • Double-click a cell to edit it, or edit every project's value for a row in the right panel.
  • Use For All copies one project's value to the others. Right-click a cell for row-level copies.
  • Compare mode stages edits instead of auto-saving. Save writes each project in turn and starts its usual refresh jobs.

Out of Scope

  • Source Data and Audit Log stay single-project; their tabs are disabled in compare mode.
  • Reserving period and table import differ by design between projects, so they are left out of the comparison.

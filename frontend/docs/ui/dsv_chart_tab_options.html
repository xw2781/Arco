Today

A replica of the current Chart tab, for comparison.

What Gets In The Way

  • Title and toggle use different names for one choice
  • 10 colours repeat: 2014 and 2024 are both red
  • Fixed 1030 × 560 panel; does not fill the window
  • Tooltip needs a direct hit on a 3px dot
  • One value at a time; no side-by-side reading
  • No axis titles
  • Origin curves start at a made-up 0m point
  • Series list: checkboxes only, no All, None or filter
  • No incremental or age-to-age view

Option A · Refined Curves

Same layout as today, every part tightened.

What Changes

  • Colour by origin age: older pale, newer dark, no repeats
  • Crosshair reads every series at one age
  • Hover a line or a list row to bring it forward
  • Values: Cumulative, Incremental, Age-To-Age
  • Series list: filter, All, None, Recent 3, Only
  • Latest diagonal value beside each series
  • Click a point to set the grid's active cell
  • Fills the window; axis titles; no 0m point

Try

  • Hover row 2017 in the list
  • Double-click a line to show only it
  • Switch Values to Age-To-Age
Low risk: renderer and series list only. Grid, tabs and saved settings are untouched.

Option B · Focus And Context

Compare a few series against all the rest.

What Changes

  • Every series stays visible as grey context
  • Up to 4 focused series get distinct colours and end labels
  • Mini triangle picks series by origin, age or cell
  • Crosshair column lights up in the triangle
  • Dashed simple average as a reference line
  • Drag the strip under the chart to zoom ages

Try

  • Click a grey line to focus it
  • Click age 36 in the triangle header
  • Drag across the zoom strip; double-click to reset
